# Лабораторная работа: Векторы и Крестики-нолики

Репозиторий содержит две независимые программы на Python:

1. **Векторы** — работа с трёхмерными векторами.
2. **Крестики-нолики** — игра для двух игроков на поле произвольного размера.

---

## Программа 1. Векторы

### Файл `vector.py` — класс `Vector`

**Назначение:** представление трёхмерного вектора, заданного начальной и конечной точками, и реализация операций векторной алгебры.

**Состояние объекта:**
- `__start` — координаты начала вектора (кортеж из трёх чисел);
- `__end` — координаты конца вектора (кортеж из трёх чисел).

**Вспомогательная функция `_is_number(value)`** — проверяет, что значение является числом (`int` или `float`), исключая `bool`.

**Конструктор `__init__(self, start, end)`:**
- принимает две точки по три координаты;
- `ValueError`, если координат не по три;
- `TypeError`, если координаты не являются числами.

**Методы доступа:**
- `get_start()` — координаты начала;
- `get_end()` — координаты конца;
- `get_x()` — компонента X (разность конца и начала по X);
- `get_y()` — компонента Y;
- `get_z()` — компонента Z.

**Основные методы:**
- `length()` — длина вектора;
- `cosine(other)` — косинус угла между векторами; `TypeError` при не-векторе, `ValueError` для нулевого вектора;
- `to_string()` — строка формата `"x1 y1 z1 x2 y2 z2"`;
- `from_string(text)` (classmethod) — создание вектора из строки из шести чисел; `ValueError` при неверном количестве или нечисловых данных;
- `copy()` — независимая копия вектора.

**Перегруженные операторы:**
- `__add__`, `__iadd__` — сложение векторов;
- `__sub__`, `__isub__` — вычитание векторов;
- `__mul__`, `__rmul__`, `__imul__` — векторное произведение двух векторов или умножение на число;
- `__truediv__`, `__itruediv__` — деление на число (запрет деления на ноль);
- `__eq__`, `__ne__` — сравнение по компонентам;
- `__hash__` — хеш по компонентам;
- `__lt__`, `__le__`, `__gt__`, `__ge__` — сравнение по длине;
- `__str__` — строка «Начало: …, конец: …»;
- `__repr__` — `Vector((...), (...))`.

### Файл `main.py` — консольный интерфейс

**Назначение:** текстовое меню для работы с двумя векторами, хранящимися в памяти в течение сеанса.

**Вспомогательные функции:**
- `input_point(title)` — запрашивает координаты X, Y, Z одной точки;
- `input_vector()` — запрашивает начальную и конечную точки, создаёт `Vector`;
- `print_vector(name, vector)` — выводит начало, конец, компоненты и длину;
- `print_menu()` — выводит главное меню.

**Главное меню:**

| Пункт | Действие |
|-------|----------|
| 1 | Создать векторы |
| 2 | Показать векторы |
| 3 | Сложить |
| 4 | Вычесть |
| 5 | Векторное произведение |
| 6 | Умножить первый вектор на число |
| 7 | Разделить первый вектор на число |
| 8 | Косинус угла |
| 9 | Сравнить длины |
| 10 | Проверить равенство |
| 11 | Сохранить в строку |
| 12 | Загрузить из строки |
| 13 | Скопировать первый вектор |
| 0 | Выход |

**Особенности UI:**
- перед операциями проверяется наличие обоих векторов; иначе выводится «Сначала создайте оба вектора.»;
- ввод обёрнут в `try/except` с обработкой `ValueError`, `TypeError`, `ZeroDivisionError`;
- сообщения на русском языке;
- цикл меню работает до ввода `0`.

### Файл `test.py` — тесты для класса `Vector`

## Программа 2. Крестики-нолики

### Файл `game.py` — класс `TicTacToe`

**Назначение:** игровое поле для крестиков-ноликов размером не менее 3×3 для двух игроков с метками `"X"` и `"O"`.

**Состояние объекта:**
- `__size` — размер стороны поля;
- `__board` — двумерный список символов (пробел — пустая клетка).

**Конструктор `__init__(self, size)`:**
- если передан другой `TicTacToe`, создаётся его копия;
- иначе проверяется, что `size` — целое число не меньше 3 (и не `bool`), иначе `ValueError`;
- создаёт пустое поле.

**Методы доступа и вспомогательные:**
- `get_size()` — размер поля;
- `_check_position(position)` — проверка пары `(строка, столбец)`: тип и диапазон; `TypeError` или `IndexError`;
- `can_set(position, value)` — можно ли поставить `"X"`/`"O"` в клетку;
- `__getitem__(position)` — чтение клетки через `game[row, col]`;
- `__setitem__(position, value)` — запись метки; `ValueError` (неверная метка, занятая клетка), `TypeError`, `IndexError`.

**Проверка победителя:**
- `_winner_on_line(positions)` — возвращает метку, если вся линия заполнена ею;
- `_winner_in_rows()`, `_winner_in_columns()`, `_winner_in_diagonals()` — проверки по строкам, столбцам, двум диагоналям;
- `winner()` — возвращает `"X"`/`"O"` или `None`.

**Прочие методы:**
- `is_full()` — заполнено ли поле;
- `__eq__`, `__ne__` — сравнение полей;
- `__str__` — человекочитаемое представление поля (метки через `|`);
- `__repr__` — представление вида `TicTacToe.from_text(...)`;
- `to_text()` / `from_text(text)` / `from_string(text)` — сериализация и десериализация поля (`X`, `O`, `-`; строки через перевод строки);
- `write(stream)` / `read(stream)` — запись и чтение через текстовый поток (файл, `StringIO`, `sys.stdout`);
- `copy()` — независимая копия поля;
- `assign(other)` — копирование состояния другого поля в текущее;
- `__copy__`, `__deepcopy__` — поддержка модуля `copy`.

Объекты класса намеренно **нехешируемы** (`__hash__ = None`), так как изменяемы.

### Файл `main.py` — консольный интерфейс

**Назначение:** интерактивная игра в крестики-нолики для двух игроков с текстовым меню.

**Вспомогательные функции:**
- `print_board(game)` — печатает поле с пустыми строками до и после;
- `input_size()` — циклически запрашивает размер поля, пока не будет введено корректное число ≥ 3;
- `input_position(size)` — запрашивает строку и столбец (нумерация с 1), преобразует в индексы с 0, проверяет диапазон; `IndexError`;
- `next_player(game)` — определяет, чей ход, подсчитывая метки `X` и `O`;
- `game_result(game)` — строка результата («Player X wins!», «Draw!») или `None`, если игра продолжается;
- `print_menu()` — выводит главное меню.

**Главное меню:**

| Пункт | Действие |
|-------|----------|
| 1 | Show board |
| 2 | Make a move |
| 3 | Check winner |
| 4 | Check whether board is full |
| 5 | Show board as text |
| 6 | Load board from text |
| 7 | Copy board |
| 8 | Save board to file |
| 9 | Load board from file |
| 10 | New game |
| 0 | Exit |

**Особенности UI:**
- интерфейс на английском языке;
- перед ходом проверяется, не завершена ли игра; при завершении выводится сообщение и предложение начать новую игру (пункт 10);
- при загрузке поля из текста строки разделяются символом `;`, который заменяется на перевод строки;
- операции ввода/вывода файлов обёрнуты в `try/except` (`OSError`, `ValueError`, `TypeError`, `IndexError`);
- внешний блок `if __name__ == "__main__"` перехватывает `EOFError` и `KeyboardInterrupt`.

### Файл `test_game.py` — тесты для класса `TicTacToe` и UI

Покрывают:
- создание поля и валидацию размера;
- доступ к клеткам, `can_set`, обработку неверных меток и позиций;
- определение победителя по строкам, столбцам и диагоналям (в том числе для больших полей);
- проверку заполненности;
- сравнение, `str`, `repr`, `to_text`/`from_text`, `from_string`;
- копирование (`copy`, `copy.copy`, `copy.deepcopy`), конструктор-копию, `assign`;
- нехешируемость;
- круговой обмен через текст, поток и файл (с использованием `tmp_path`);
- интеграционные тесты UI: выход, победа `X`, ничья, отклонение слишком маленького размера, некорректные ходы, работа с текстом и копией, определение следующего игрока после загрузки, работа с файлами (сохранение, загрузка, ошибки).
