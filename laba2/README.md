# Лабораторная работа №2 — объектная модель «Кулинария»

## Структура проекта

Проект организован в папке `laba2/`. Внутри находятся пакет `culinary`, набор тестов `tests` и файлы запуска/настройки.

- `culinary/ingredients` — базовый ингредиент и девять специализированных ингредиентов.
- `culinary/recipes` — рецепты, шаги, ингредиенты рецепта, категории, время, порции, книга и менеджер рецептов.
- `culinary/dishes` — супы, салаты, десерты, выпечка, основные блюда, напитки, соусы и гарниры.
- `culinary/kitchen` — кухня, инструменты, оборудование и инвентарь.
- `culinary/warehouse` — склад, запасы, складские позиции, поставщики, закупки и контроль сроков годности.
- `culinary/people` — базовый человек, повар, клиент, кулинар, диетолог и помощник кухни.
- `culinary/orders` — заказы, позиции заказа, меню, оплата и доставка.
- `culinary/nutrition` — пищевая ценность, расчёт калорий, диетические планы и аллергены.
- `culinary/exceptions` — собственные исключения предметной области.
- `tests` — автоматические тесты основных подсистем.

Полный перечень файлов приведён в [`ДОКУМЕНТАЦИЯ_ФАЙЛОВ.md`](ДОКУМЕНТАЦИЯ_ФАЙЛОВ.md). Описание классов — в [`ДОКУМЕНТАЦИЯ_КЛАССОВ.md`](ДОКУМЕНТАЦИЯ_КЛАССОВ.md). История исправлений — в [`ОШИБКИ_И_ИСПРАВЛЕНИЯ.md`](ОШИБКИ_И_ИСПРАВЛЕНИЯ.md).

## Наследование и связи

- `Ingredient` — базовый класс для `Vegetable`, `Fruit`, `Meat`, `Fish`, `DairyProduct`, `Spice`, `Flour`, `Oil`, `Egg`.
- `Person` — базовый класс для `Chef`, `Customer`, `KitchenWorker`, `Cook`, `Nutritionist`, `KitchenAssistant`.
- `CookingEquipment` — базовый класс для `Oven`, `Refrigerator`, `Stove`, `Blender`.
- `KitchenTool` — базовый класс для `FryingPan` и `Saucepan`.
- `Dish` — базовый класс для специализированных блюд: `Soup`, `Salad`, `Dessert`, `Pastry`, `MainCourse`, `Beverage`.
- `Recipe` хранит объекты `RecipeIngredient` и `RecipeStep`.
- `RecipeIngredient` ссылается на объект `Ingredient`.
- `Dish` связан с `Recipe`; позиции заказа ссылаются на блюда.
- `Order` связан с клиентом и содержит позиции `OrderItem`; `Payment` и `Delivery` работают с заказом.
- `Warehouse` и `Stock` управляют складскими позициями и партиями продуктов.

## Установка и запуск на macOS

Требуется Python 3.10 или новее. В терминале перейдите в корень папки `laba2`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

В `requirements.txt` указаны только средства тестирования и покрытия, прикладной код использует стандартную библиотеку Python.

## Запуск тестов

```bash
python3 -m pytest -q
```

Проверка покрытия:

```bash
python3 -m pytest --cov=culinary --cov-branch --cov-report=term-missing
```

Проверка синтаксиса:

```bash
python3 -m compileall -q culinary main.py tests
```

## Примечание о тестировании

Текущий набор содержит тесты основных сценариев всех ключевых подсистем. При контрольном запуске перед упаковкой выполнено 20 тестов: все 20 прошли. Текущее покрытие тестами — около 53%; требование покрытия свыше 90% пока не выполнено и требует расширения тестов.
